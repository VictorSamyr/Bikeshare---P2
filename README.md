# Bikeshare - Sistema de Bicicletas Compartilhadas

Projeto desenvolvido para a disciplina de Programação 2 (POO) - Instituto de Computação (IC) / UFAL.

## Milestones

- **Milestone 1:** Implementação das User Stories 1 a 9 (cadastro, consulta, alteração e remoção de usuários, cadastro de estações, gestão de bicicletas convencionais e elétricas, consulta de disponibilidade, retirada e devolução de bicicletas e persistência).

### Observações
- Os parâmetros de tarifação e os limites de negócio (tarifas, franquia, carência, tempo máximo e bateria mínima) ficam no arquivo `bikeshare.properties`, na raiz do projeto.
